# מתכונים - פרויקט ניהול מתכונים

ברוכים הבאים לפרויקט ניהול המתכונים!

## תיאור
מערכת לניהול, שמירה וחיפוש מתכונים.

## תכונות עיקריות
- הוספה, עריכה ומחיקה של מתכונים
- חיפוש לפי שם, קטגוריה או מרכיבים
- ממשק משתמש נוח

## התקנה והרצה

1. לשכפל את המאגר:
    ```bash
    git clone <repository-url>
    ```
2. להתקין תלויות:
    ```bash
    npm install
    ```
3. להריץ את הפרויקט:
    ```bash
    npm start
    ```
